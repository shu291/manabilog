# 📚 まなびログ — 学生のための学習管理アプリ

課題・勉強タイマー・目標・統計をひとつにまとめた、**登録不要・完全無料・オフライン対応**の学習管理アプリです。
HTML1ファイルだけで動きます（外部ライブラリなし）。

## ✨ 主な機能

- **🏠 ホーム** — 今日/今週の勉強時間、連続日数（🔥ストリーク）、締切が近い課題、週間グラフ
- **✅ 課題管理** — 教科・優先度・締め切り・メモ、フィルタ／並べ替え、完了チェック
- **⏱️ 勉強タイマー** — ポモドーロ＋ストップウォッチ。タブを閉じ気味でも正確に計測、完了時に通知
- **🎯 目標** — 週間目標・教科別目標と進捗バー
- **📊 統計** — 14日間の棒グラフ、教科別ドーナツ、8週間のヒートマップ、累計・平均
- **⚙️ 設定** — ダークモード、データの書き出し／読み込み、リセット

## 🚀 使い方

そのまま [公開ページ](https://shu291.github.io/manabilog/) を開くだけ。スマホのホーム画面に追加すればアプリのように使えます。

### 手元で動かす

```bash
git clone https://github.com/shu291/manabilog.git
cd manabilog
open index.html          # もしくは python3 -m http.server 8099
```

## 🔒 データについて

すべてのデータは**あなたの端末のブラウザ内（localStorage）だけ**に保存されます。サーバーには何も送信されません。
機種変更の前は「設定 → データを書き出す」でバックアップしておきましょう。

## 🛠 技術

- 単一 HTML / CSS / Vanilla JavaScript（依存ゼロ）
- localStorage による永続化
- レスポンシブ（PC・スマホ対応）、ライト／ダークテーマ
